# LLM Learning Project

코드잇 스프린트 AI 엔지니어 부트캠프 커리큘럼을 기반으로 한 개인 학습 저장소입니다.

## 학습 과정

| 단계 | 기간 | 주제 |
|------|------|------|
| 프리코스 | 수강 전 | 파이썬 기초 |
| 1~2주차 | 1~2주 | 데이터 분석 (NumPy, Pandas, Matplotlib) |
| 2~4주차 | 2~4주 | 머신러닝 (scikit-learn, XGBoost) |
| 4~5주차 | 4~5주 | 딥러닝 (CNN, RNN, AutoEncoder) |
| 5~7주차 | 5~7주 | PyTorch 심화 (ResNet, autograd) |
| 7~13주차 | 7~13주 | 컴퓨터 비전 (YOLO, GAN, Diffusion) |
| 13~16주차 | 13~16주 | 자연어 처리 (BERT, GPT, HuggingFace) |
| 16~21주차 | 16~21주 | LLM (RAG, LangChain, LoRA) |
| 21~22주차 | 21~22주 | Docker · 추론 최적화 |
| 22~29주차 | 22~29주 | 모델 배포 (FastAPI, GCP, Triton) |

## 디렉토리 구조

```
LLM-project/
├── precourse/                  # 파이썬 기초
├── week01_02_data_analysis/    # 데이터 분석
├── week02_04_ml/               # 머신러닝
├── week04_05_deeplearning/     # 딥러닝
├── week05_07_pytorch/          # PyTorch
├── week07_13_cv/               # 컴퓨터 비전
├── week13_16_nlp/              # 자연어 처리
├── week16_21_llm/              # LLM
├── week21_22_docker/           # Docker
└── week22_29_deployment/       # 모델 배포
```

각 폴더는 `notes/`(개념 정리), `practice/`(실습 코드), `project/`(미션·프로젝트)로 구성됩니다.
